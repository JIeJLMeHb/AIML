## Конфигурация

```python
TASK = 2
VARIANT = 3
SEED = 42
USE_FULL_DATA = False
DEV_N = 20_000
```

- `TASK = 2` — выбирает датасет «Качество воды» из словаря `TASKS`.
- `VARIANT = 3` — выбирает метод **решающее дерево**; второй обязательный метод — MLP.
- `SEED = 42` — фиксированное зерно генератора случайных чисел. Оно делает разбиение выборки, инициализацию весов и случайные процессы воспроизводимыми: при повторном запуске результаты не меняются.
- `DATA_DIR` — папка, где лежит CSV; если есть `data/water_potability.csv`, берётся папка `data`, иначе текущая директория.
- `USE_FULL_DATA = False` — флаг разработки: предполагается работа на подвыборке.
- `DEV_N = 20_000` — максимальный размер подвыборки. В вашем датасете всего 3276 объектов, поэтому подвыборка фактически не применяется.
- `MIN_AUC = 0.65` — минимальный требуемый AUC для задачи 2.

### Стандартизация

```python
class Standardizer:
    fit(X)
    transform(X)
    fit_transform(X)
```

- `fit(X)` запоминает среднее `mean_` и стандартное отклонение `std_` **только по обучающей выборке**.
- `transform(X)` переводит каждый признак в z-оценку: \((x - \text{mean}) / \text{std}\).
- `std_[std_ == 0] = 1.0` защищает от деления на ноль, если у признака нет разброса.
- Стандартизация нужна прежде всего для MLP: признаки имеют очень разные масштабы, например `Solids` порядка десятков тысяч, а `ph` — единиц. Без неё градиентный спуск может обучаться плохо.
- Для решающего дерева масштаб не принципиален: дерево сравнивает значение с порогом, а не измеряет расстояния. Но стандартизация не мешает и применяется единообразно. ### Критерий Джини

```python
def gini(self, y):
    p = y.mean()
    return 2.0 * p * (1.0 - p)
```

- `p` — доля класса 1 в узле.
- Джини равно 0, если узел чистый: все объекты одного класса.

## MLP

### Идея

MLP — многослойный перцептрон: линейные преобразования чередуются с нелинейностью ReLU, а на выходе sigmoid даёт вероятность класса 1. В отличие от дерева, MLP обучается градиентным спуском.

### Параметры

```python
MLP(
    hidden=(32, 16),
    lr=0.05,
    nepochs=30,
    batchsize=128,
    l2=0.0,
    seed=SEED
)
```

- `hidden` — кортеж с числом нейронов в скрытых слоях. `(32, 16)` — первый скрытый слой 32 нейрона, второй — 16.
- `lr` — learning rate, скорость обучения. Слишком маленький — обучение медленное; слишком большой — loss может «прыгать» или расходиться.
- `nepochs` — число проходов по всему обучающему набору.
- `batchsize` — число объектов в одном мини-батче градиентного спуска.
- `l2` — коэффициент L2-регуляризации. Чем больше, тем сильнее штрафуются большие веса и тем проще модель; это борется с переобучением.
- `seed` — зерно для случайной инициализации весов и перемешивания батчей. ### Forward pass

### Loss и градиенты

```python
loss = -mean(y*log(p) + (1-y)*log(1-p)) + reg
delta = (p - y) / n
```

- Используется бинарная cross-entropy: она штрафует модель сильнее, когда она уверенно ошибается.
- `np.clip(p, 1e-12, 1 - 1e-12)` защищает от `log(0)`.
- `reg = 0.5 * l2 * sum(W^2)` — L2-штраф весов.
- `delta = (p - y) / n` — градиент cross-entropy по выходу сети; это стандартный результат для sigmoid + binary cross-entropy.
- В обратном проходе градиент передаётся через ReLU: там, где `z <= 0`, градиент обнуляется.
- Градиенты весов: `a_prev.T @ delta`; смещений: `delta.sum(axis=0)`. ### Обучение

for epoch in range(nepochs):

    for start in range(0, n, batchsize):

## ROC и AUC

```python
def roc_curve_np(ytrue, scores):
    ...
def auc_np(fpr, tpr):
    return np.sum(np.diff(fpr) * (tpr[1:] + tpr[:-1]) / 2.0)
```

- ROC-кривая показывает зависимость TPR от FPR при разных порогах.
- TPR = recall = \(TP / (TP + FN)\).
- FPR = \(FP / (FP + TN)\).
- AUC — площадь под ROC-кривой: вероятность того, что случайно выбранный положительный объект получит более высокий score, чем случайно выбранный отрицательный.
- AUC 0.5 означает случайное ранжирование; AUC 1.0 — идеальное.
- `auc_np` использует формулу трапеций: площадь под кусочно-линейной ROC-кривой.
